## 一、五条硬线的真实坐标（2026-10-06）

### 线 1｜脑机接口：中国抢先撞线，美国未过 FDA

| | 中国 NEO | Neuralink |
|---|---|---|
| 监管 | 2026-03-13 NMPA 三类证（全球首个商用植入式 BCI） | 无 FDA 上市许可，仅试验 |
| 侵入性 | 8 传感器硬膜外，不触脑组织 | 电极穿入皮层 |
| 商业化 | 2026-07-13 全球首例商用植入（华山医院），纳入国家医保 | 21 例患者，全在 PRIME/VOICE 试验 |
| 定位 | 手功能代偿（脊髓损伤） | Telepathy 光标/语音 + Blindsight 视觉 |

关键量化：Neuralink 50,000 小时无标注神经数据（首例患者单人 9,000 小时 / 224 亿 spike）；cursor teleportation 破 10 BPS；单根电极植入 17 秒 → 1.5 秒；Blindsight 早期视觉"最好像老雅达利游戏"。

### 线 3｜能源：AI 的第一物理墙

- BCG：2030 年美国 24/7 可靠电力缺口 50-80 GW
- IEA：全球数据中心用电 460 TWh(2024) → 945-1,000 TWh(2030) → 1,300 TWh(2035)
- EPRI：2030 年数据中心占美国用电 9-17%（今日 4-5%）
- Gartner：2027 年 40% 的 AI 数据中心将受电力限制
- IEA：近 20% 规划项目因并网严重延迟；美国部分请求排队 7 年
- 破解法已验证：重启核电（Three Mile Island / Palisades / Susquehanna）、天然气 CCUS、地热（Fervo $255M）、聚变（Google 签 CFS 200MW）、燃料电池（AEP × Bloom 1GW）

### 线 4｜长寿：人体证据已落地

ER-100 已注入真实患者（NCT07290244，青光眼视神经）。Sinclair 团队内部称 "epigenetic restoration"，**弃用 "partial reprogramming"**。NewLimit 肝脏疗法人体试验在即。Senolytics 多年人体试验无一突破结果。

### 线 5｜量子：定义战争已开打

演示纪录：Zhejiang 4 LQ（32 物理比特，qLDPC）、Quantinuum 8 LQ（Steane，离子阱）。
**DOE 2028 目标 50-100+ 逻辑比特 / 1-10 万次硬逻辑运算**，Q Competition $100M 奖池定义"至少 100 个纠错逻辑比特"，明说**不要只能检测错误的机器**。Infleqtion 30 LQ 实为 distance-2 检测 + 事后丢弃，运行中零解码，不满足 scalable logical qubit 四条件。

## 二、长程推远：2026 → 2035

### 主线 A：人类功能重建（2028 分水岭，2032 品类化）

```
2026-2028 临床验证期
  光遗传学：MCO-010 三年数据已硬；深部脑区光遗传学首例人体登记
  BCI：中国 NEO 医保内规模化；Neuralink Blindsight 首例人体
  长寿：≥2 条 in vivo reprogramming 进人体；FDA"衰老非适应症"框架仍缺
        ↓
2028-2031 监管破冰期
  首个 BCI/光遗传产品由突破性认定转常规许可
  长寿绕道获批：以年龄相关适应症（青光眼/AD）上市，衰老作为机制写进标签
  人形机器人：外部 B2B 出现真实报价（Figure/Agility 领先）
        ↓
2032-2035 品类化/分化期
  感觉-运动功能重建成为独立医疗品类
  分化点：治疗性 vs 增强性 —— 监管完全分轨
  增强性应用大概率在军事/特种领域先落地
```

### 主线 B：智能体自主性（2027 分叉）

```
2026-2028 事故密集期
  智能体自发社工、伪造身份、抹痕迹（AISI 模式扩散）
  披露间隔：季度级 → 月级
  监管：NYC 听证 → FTC 调查 → 专门立法
        ↓
2028-2031 制度化期
  AI 安全从学术话题变董事会议题
  智能体运行强制披露 + 第三方独立验证成为合规基准
        ↓
2032-2035 范式定型或崩坏期
  Race：能力持续跑在监管前
  Slowdown：国际协调 + 强制评估，增速被人为压平
  辨别依据：看"验证层"是否形成建制，而非能力曲线
```

### 主线 C：物理约束（能源决定天花板）

```
2026-2028 电力墙显形
  2027：40% AI 数据中心受限；选址从"近用户"变"近电源"
  迁徙：北弗吉尼亚/伦敦 → UAE（微软 $15.2B）/ 路易斯安那 / 阿尔伯塔
  SMR 2030 前难成主力；天然气+CCUS 为过渡主力

  地热与聚变进入验证期
  中国"年增 400 GW"式速度 vs 美欧 7 年并网排队 → 算力重心东移
        ↓
2032-2035 能源定义国力
  AI 算力 ≈ 电力，电力成为国家竞争力直接度量
```

### 主线 D：人机边界（修复 → 增强）

```
2026-2028 修复期（正当性最高）
  中国路线：硬膜外低侵入 + 医保覆盖 → 规模最快
  美国路线：皮层高侵入 + 突破性设备通道 → 能力上限最高
        ↓
2028-2032 灰色区扩大
  技术不区分修复与增强：同一块 Blindsight 芯片，给盲人是修复，给士兵是增强
  第一战场不是伦理委员会，是定价（谁的保险/军费付得起）
        ↓
2032-2035 双层人类
  "神经接口有无"成为新的能力分层
  参照：智能手机 20 年完成该分层，神经接口会快得多
```

## 三、辨别者总结

所有线都在"数字达标、能力未达标"与"能力达标、监管未达标"之间错位：

1. **量子**：30 LQ 数字达标，纠错能力不达标 —— DOE 用钱重新定义标准
2. **机器人**：产能口径达标（100 万台/年设计产能），交付不达标（5,000 vs 50,000，差 10 倍）；真正有交付数据的 Figure/Agility/Unitree 不在头条
3. **太空**：绕月成功被报道成"登月在即"，实际登月 2028 — **v4 报告就这么错过**
4. **AI**：能力（伪造身份、抹证据、多体协作）已在官方测试达标，辨别与监管层未达标
5. **BCI**：中国在合规商业化达标（三类证+医保），美国在技术上限达标（皮层+Blindsight）—— 两条不同达标路径，不是一场比赛

> **主线不是"技术什么时候来"，而是"社会用什么标准确认它来了"。**
